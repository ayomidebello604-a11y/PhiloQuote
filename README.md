# 💡 Quote Explorer

A fully responsive web application for exploring, discovering, and reflecting on philosophical quotes. Browse 150+ quotes, filter by philosophy school, save favorites, and journal your personal reflections—all with smooth animations and persistent storage.

## About

Quote Explorer helps users discover philosophical wisdom through an intuitive interface. Whether you're interested in stoicism, existentialism, or any other philosophical school, this app makes it easy to explore quotes, connect with thinkers, and document your personal insights.

## ✨ Features

- **Quote Discovery** - Browse 150+ philosophical quotes with author attribution
- **Philosophy School Filtering** - Filter quotes by different philosophical schools with detailed descriptions
- **Smart Search** - Search quotes by content or author name
- **Quote of the Day** - Randomly selected daily featured quote
- **Favorites System** - Save and organize your favorite quotes
- **Journal** - Write personal reflections and notes on specific quotes
- **Smooth Animations** - Scroll-triggered animations for engaging UX
- **Fully Responsive** - Works seamlessly on mobile, tablet, and desktop
- **Persistent Storage** - LocalStorage saves favorites and journal entries across sessions
- **Fixed Navigation** - Always-accessible navbar with mobile hamburger menu

## 🛠️ Tech Stack

- **React 19** - Modern UI library with latest hooks
- **Vite 8** - Fast build tool and dev server
- **React Router v7** - Client-side routing
- **Tailwind CSS 4** - Utility-first CSS framework
- **Framer Motion** - Advanced scroll-triggered animations
- **React Icons** - Icon library for UI elements

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Visit `http://localhost:5174`

## 📱 Design

Mobile-first responsive design with optimized layouts for 320px–1440px+ screens. Hamburger menu on mobile, full navigation on desktop.

## 💾 Data

Quotes fetched from DummyJSON API. User data (favorites, journal entries) stored locally in browser.
